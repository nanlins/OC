# web

> 用途：Web 管理控制台前端（React + Vite）

## 内容清单
- `frontend/`：React 前端源码（6 页面 + 三语 i18n + SSE 事件直播）
- `frontend/src/pages/`：Dashboard/Sessions/Groups/Wirings/Approvals/Audit
- `frontend/src/store/`：全局状态存储（useSyncExternalStore + 定时刷新）
- `frontend/src/api/`：API 客户端（fetch + Bearer token + 本地化错误体）
- `frontend/src/i18n/`：三语 i18n（zh/en/ja + cycleLocale）
