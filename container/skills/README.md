# skills

> 用途：20 个容器技能，以 SKILL.md 形式注入 Agent 系统提示

## 内容清单
- `welcome`：欢迎技能，Agent 自我介绍与基础交互规则
- `memory-management`：记忆管理，何时存储/检索/整理 Agent 记忆
- `rag-search`：RAG 检索，如何用 kb_search 工具检索知识库
- `code-review`：代码审查，代码质量检查与修复建议
- `scheduler-helper`：调度辅助，定时任务创建/管理/排查
- `web-research`：网页检索，web_fetch/web_search 工具使用指南
- `translator`：翻译，多语言翻译任务
- `summarizer`：摘要，文本/对话总结
- `test-writer`：测试编写，自动生成测试用例
- `git-helper`：Git 辅助，版本控制操作
- `docker-helper`：Docker 辅助，容器操作
- `data-analyst`：数据分析，数据处理与可视化
- `report-writer`：报告撰写，结构化报告生成
- `email-drafter`：邮件起草，邮件撰写与发送
- `todo-manager`：待办管理，任务跟踪与优先级
- `knowledge-curator`：知识整理，信息归档与索引
- `browser-automation`：浏览器自动化，网页操作与截图
- `frontend-engineer`：前端工程，UI 组件开发
- `self-customize`：自我定制，Agent 行为与偏好调整
- `escalation`：升级，复杂问题人工介入
