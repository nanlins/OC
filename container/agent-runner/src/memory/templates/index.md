# Memory Index

You maintain this file as your long-term memory. It is **authoritative data**:
the index lists every concept file you create; concept files hold the actual facts.

## Concept Map

One line per concept file. Keep this list current: create an entry when you make a
new file, remove it when you delete one.

- (e.g. `projects/foo.md` — active project context)
- (e.g. `preferences/formatting.md` — code style the user asked for)

## Rules

- Record patterns, not instances: "user prefers X" not "user did X once".
- Facts are corrected **in place** — edit the file, do not append duplicate lines.
- If a fact stops being true, rewrite or delete it rather than annotating it.
- Files other than this index and `system/definition.md` are yours to create and
  reshape freely; the index and doctrine stay in their fixed locations.
