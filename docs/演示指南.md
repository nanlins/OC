## 面试官可能追问

**Q: 双 DB 怎么保证跨 mount 一致性？**
A: journal_mode=DELETE（WAL 的 mmap -shm 不跨 VirtioFS 刷新），主机每次 open-write-CLOSE，偶/奇 seq 分属主机/容器。

**Q: Guard 怎么做到 fail-closed？**
A: defineGuardedAction 返回 branded 对象，非铸造值一律 DENY。审批重放时结构检查重跑+查库验活行，恰好执行一次。

**Q: 9 个通道怎么实现的？**
A: ChannelAdapter 接口——通道适配器只返回平台 ID，不知道 agent group/session。主机做映射。Telegram 用长轮询、Discord/Slack 用 WebSocket、飞书/钉钉/企微用 REST API。
