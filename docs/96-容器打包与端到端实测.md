# 容器打包与端到端实测

> 用途：记录收束期补齐的 agent 容器打包（Dockerfile + 构建脚本 + provider key 接线）与免 key 端到端实测；此前「无 Dockerfile 导致 agent 对话跑不了」的缺口在此闭合。

## 一、背景
验收时发现：主机编排与 agent-runner 源码齐备，但**无 Dockerfile/构建脚本**，`container-runner` spawn 所用镜像 `openclaw-agent-<slug>` 无法构建，agent 对话不可实测。本阶段补齐打包并跑通端到端。

## 二、交付
1. **`container/Dockerfile`**：基镜 `oven/bun:debian`（自带 bash+bun）；`bun install --frozen-lockfile` 装 agent-runner 依赖；烘焙 `src/` 与 `skills/`（OpenClaw 运行时仅挂 `/workspace`，与 nanoclaw「/app/src 运行时 RO 挂载」不同）；宿主 spawn 以 `--entrypoint bash -c "exec bun run /app/src/index.ts"` 覆盖入口，`--init` 由宿主 hardeningArgs 提供。
2. **`container/build.ts` + `npm run build:container`**：import `config.CONTAINER_IMAGE` 保证镜像名与宿主 spawn 一致（sha1(projectRoot)[:8] 作用域），跨平台（Windows 可用，替代 nanoclaw 的 bash build.sh）。产物 `openclaw-agent-80a096de:latest`（约 276MB）。
3. **provider key 接线**：新增 `src/providers/{openai,claude,index}.ts`，`registerProviderContainerConfig` 把 `.env`（优先）/`process.env` 的 `OPENAI_API_KEY/OPENAI_BASE_URL`、`ANTHROPIC_API_KEY/ANTHROPIC_BASE_URL` 经 `-e` 显式注入容器（不靠环境继承、不写宿主 process.env）；`ollama` 复用 OpenAI 兼容协议。`src/index.ts` 引入 providers barrel。
4. **实测脚本**：`scripts/chat.ts`（管道对话，静默退出/硬超时）、`scripts/send-once.ts`（发一条即退，用于触发 messaging_group 自动创建）、`scripts/set-group-provider.ts`（运维改写 container_configs.provider）。

## 三、修复的真实 bug
1. **provider 种子丢失**：`configFromDb` 调 `ensureContainerConfig(id)` 未传群组 provider，首建行被默认 `claude` 覆盖建组所选 provider（实测 mock 组建出 claude 容器、回 401）。修复为以 `getAgentGroup(id).agent_provider` 打戳。
2. **openai provider 双 system**：容器侧 `openai.ts` 将 system 提示连推两次，去重。

## 四、端到端实测（免 key，mock provider）
链路：`CLI 命名管道 → router → 会话 → inbound.db → Docker 容器(mock) → outbound.db → 投递 → 管道回复`。
- 建组 `mocktest`（provider=mock）→ 首条消息触发 cli/local messaging_group 自动创建 → `wirings create` 接线 → `chat.ts` 发消息收到 mock echo，无报错；Web 控制台可见 active/running 会话。

## 五、已知事项
- **测试与运行中主机抢命名管道**：`cli-channel/cli` 集成测试与在跑主机共用 `\\.\pipe\openclaw-{chat,ctl}-<slug>`，主机运行时该 4 例报 `EADDRINUSE`（环境冲突，非代码回归；停主机后 290 全绿）。
- **真实 LLM 对话已跑通**：`.env` 配 DeepSeek（`OPENAI_BASE_URL=https://api.deepseek.com/v1`，模型 `deepseek-v4-flash`，经 `/v1/models` 发现）；建 provider=openai 群组 → `set-group-model.ts` 写 model → 接 cli → `chat.ts` 收到真实中文回复。管线：消息→路由→容器(openai provider)→DeepSeek→outbound→投递。
